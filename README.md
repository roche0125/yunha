# Mood & Metric (무드 앤 메트릭)

음악의 분위기와 감정을 분석하고 사용자의 기분과 날씨 변수를 기반으로 AI로 맞춤형 플레이리스트를 생성하는 웹 서비스

### 기능

main

1. 페이지 안내 및 소개
2. 춤추는 사람 애니메이션

***

music

1. CD가 돌아가며 곡 이름과 가수 이름을 입력했을 때에는 CD 위에 이름이 뜬다.
2. 곡 이름과 가수 이름을 입력하면 음악을 분석한 후 곡의 분위기, 어울리는 색, 곡 속의 감정 비율, 대표 단어 5개를 알려준다.
3. Listen 버튼을 누르면 분석한 곡을 유튜브에서 바로 들을 수 있다.
4. CD와 단어 칸에 네온 효과를 넣음.

***

playlist

1. 음악 파형 애니메이션
2. 현재 감정, 날씨, 원하는 플레이리스트의 길이, 현재 상황, 원하는 음악 장르를 선택하면 그에 맞는 음악들을 선별해 플레이리스트를 추천해준다.
3. 추천 이유와 플레이리스트 분위기를 알려준다.
4. 추천받은 음악 옆의 Listen 버튼을 누르면 유튜브에서 바로 감상이 가능하다.

***

### 사용법

1. 사이드바에서 music 또는 playlist를 선택한다.
2. music에서는 음악의 이름과 가수 이름을 입력하고 analyze 버튼을 누른다.
3. playlist에서는 현재 기분, 날씨, 상황, 길이, 장르 등을 입력하고 build 버튼을 누른다.
